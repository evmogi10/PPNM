1. PROJECT DESCRIPTION & IMPLEMENTATION
--------------------------------------------------------------------------------
This project implements the Lanczos Tridiagonalization algorithm to compress a large, dense N x N symmetric matrix into a much smaller n x n tridiagonal matrix T, preserving the extreme eigenvalues. I applied this to calculate the ground state energy of a discretized Hydrogen atom (using a radial Schrödinger equation).

During the initial implementation, I ran into the well-known numerical instability of the raw Lanczos method: floating-point errors caused the basis vectors to lose orthogonality, generating "ghost" eigenvalues. To fix this, I implemented Full Gram-Schmidt Reorthogonalization (the "purification" method by Ojalvo and Newman) inside the main loop. This successfully stabilized the Krylov subspace.

2. EMPIRICAL RESULTS: CONVERGENCE & COMPLEXITY
--------------------------------------------------------------------------------
By analyzing the generated data (`convergence.txt`, `timing.txt`), I observed two main things about the algorithm's behavior:

* Strong Compression & Convergence: For the Hydrogen system (rmax = 20.0, dr = 0.1, making N = 200), the ground state energy converged surprisingly fast. With a subspace of just n = 60, the absolute error compared to the full Jacobi baseline dropped to 2.54e-07. This was a great practical demonstration of how Lanczos achieves near machine-precision while solving a problem less than a third of the original size.

* The Cost of Stabilization: Classical theory states raw Lanczos has a time complexity of O(d * N * n). However, because I added the Full Gram-Schmidt purification, the algorithm now has to check every new vector against all previously generated ones. I realized this adds a quadratic cost. I tested this empirically in my timing data, and it perfectly matches a scaling of O(d * N * n + N * n^2). The performance ratio remained asymptotically constant (around 10^-8) across iterations, which validates that my code is behaving exactly as the math predicts.

3. INVESTIGATION: TUNING JACOBI FOR TRIDIAGONAL MATRICES
--------------------------------------------------------------------------------
I also investigated whether we could modify the classical Jacobi algorithm to take advantage of the tridiagonal matrix T generated by Lanczos. I concluded that this is practically impossible due to a geometric "fill-in" problem.

Even if we optimize the first Jacobi rotation to target a subdiagonal element at (p, p+1), the orthogonal transformation ends up mixing entire rows and columns. This immediately spawns new non-zero elements at positions like (p-1, p+1) and (p, p+2)—completely outside the tridiagonal band. 

Because of this, the matrix quickly loses its tridiagonal sparsity and becomes dense again, driving the complexity back up to O(N^3). Therefore, to truly take advantage of the Lanczos reduction in a real-world scenario, we would need to use algorithms that natively preserve the tridiagonal shape (like the QR algorithm). 

(Note: In my actual code, I am still using our standard Jacobi solver on T, but only because n is compressed to such a small size (n <= 60) that the O(n^3) cost is negligible for this specific exercise).
