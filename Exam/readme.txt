1. PROJECT DESCRIPTION & IMPLEMENTATION DETAILS
--------------------------------------------------------------------------------
This project implements the Lanczos Tridiagonalization algorithm for real symmetric matrices. The algorithm is an adaptation of power methods used to find extreme eigenvalues. It reduces the original N x N matrix into a much smaller n x n tridiagonal matrix T, acting as a lossy compression scheme that preserves extreme eigenvalues. 

To test its effectiveness, I calculated the ground state energy of the radial Schrödinger equation for a discretized Hydrogen atom. Because the pure Lanczos algorithm suffers from numerical instability due to a loss of orthogonality (which generates "spurious" or ghost eigenvalues), I implemented Full Gram-Schmidt Reorthogonalization (the "purification" method introduced by Ojalvo and Newman) inside the main loop to guarantee the stability of the Krylov subspace.


2. ANALYSIS OF EMPIRICAL RESULTS (CONVERGENCE & EFFICIENCY)
--------------------------------------------------------------------------------
The data pipelines generated by the simulation (`convergence.txt`, `timing.txt`) yield two key conclusions about the behavior of my implementation:

* Accelerated Convergence: For our system with radius rmax = 20.0 and step dr = 0.1, the original matrix has a size of N = 200. Looking at the convergence file, the ground state is approximated extremely quickly. With a subspace of just n = 60, the absolute error compared to the full Jacobi baseline drops to 2.54e-07. This demonstrates the compression power of the Lanczos process: we achieve near machine-precision by solving a problem less than a third of the original size.

* Validation of True Complexity: Classical theory dictates that raw Lanczos has a cost of O(d * N * n). However, to stabilize the algorithm, I included the purification of vectors against all previously generated vectors. This adds a quadratic computational cost with respect to the subspace size. In `timing.txt`, I have empirically demonstrated that the true time complexity of my program scales exactly as O(d * N * n + N * n^2). The performance ratio remains asymptotically constant (on the order of 10^-8) for all iterations, mathematically validating the implementation.


3. THEORETICAL ANALYSIS: INCOMPATIBILITY OF JACOBI WITH TRIDIAGONAL MATRICES
--------------------------------------------------------------------------------
A natural question when obtaining a reduced tridiagonal matrix is whether we can tune the classical Jacobi algorithm to take advantage of this structure. 
The answer is conclusively NO, due to a geometric "fill-in" problem.

Although the first Jacobi rotation could technically be designed to have a linear cost, applying an orthogonal transformation matrix to zero out a subdiagonal element at coordinates (p, p+1) combines entire rows and columns. This instantly generates new non-zero elements in positions such as (p-1, p+1) and (p, p+2), which fall completely outside the three main diagonals. 

After just a few iterations, the matrix completely loses its tridiagonal structure and becomes dense, reverting the algorithm's complexity back to its standard O(N^3) cost. Therefore, for matrices reduced by Lanczos, it is imperative to use methods that natively preserve the tridiagonal shape, such as the QR algorithm with implicit shifts, which runs asymptotically optimal in O(n^2) time for tridiagonal matrices. (Note: In this code, standard Jacobi is still used on T only because n is compressed to such a small size (n <= 60) that the O(n^3) cost is negligible compared to the full O(N^3) system).
